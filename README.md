# DACHBYTE OFFICE

DACHBYTE OFFICE é um escritório virtual de agentes de IA para operações de e-commerce, marketplaces, ERP, Hub, finanças, margem, precificação, Ads e inteligência competitiva.

Este repositório é privado e inicia sua implementação a partir do handoff arquitetural aprovado em 2026-08-19.

## Status

Sprint 0 — Foundations.

## Regra central

Todo estado operacional exibido no Office deve corresponder a um estado real do backend, tarefa, reunião, aprovação, evento ou atividade de agente.
